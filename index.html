Learn It!

Let's learn to add money carefully. Keep the place values aligned, calculate one column at a time, and check your answer.

How to Add Money

Use these four steps whenever you solve an addition question.

1. Write Arrange the amounts in columns.
2. Align Keep the same place values together.
3. Add Add from the smallest place value and regroup when needed.
4. Check Estimate or use the inverse operation to check.
Worked Example
RM1,250 + RM2,375 = RM3,625

Thousands: 1,000 + 2,000 = 3,000
Hundreds: 200 + 300 = 500
Tens: 50 + 70 = 120
Ones: 0 + 5 = 5

Total: RM3,625

Quick Practice

A pupil buys two items costing RM3.20 and RM2.50.

RM3.20 + RM2.50 = RM5.70

If the pupil pays RM10.00:

RM10.00 − RM5.70 = RM4.30

So, the change is RM4.30.
